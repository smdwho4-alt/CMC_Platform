3. Google Sheets 운영 팁

📌 데이터 유효성 검사 설정 권장
Google Sheets에서 ENUM 컬럼(F·G·J·M·O·Q·AA·AB·AC)에 데이터 유효성 검사(드롭다운)를 설정하면 입력 오류를 방지할 수 있습니다.
설정 방법: 해당 열 선택 → 데이터 → 데이터 유효성 검사 → 드롭다운(범위 또는 항목) 설정
🔒 보안 설정 필수
• 시트 공유: '제한됨' (특정 계정만 접근)
• A열(예약번호), B열(접수일시), P열(예약확정일): 시트 보호 → 편집 잠금 (Apps Script 제외)
• 개인정보 컬럼(C·D·E): 운영 관계자 외 접근 차단
📊 자동 대시보드 활용
별도 시트를 만들어 COUNTIF·SUMIF·AVERAGEIF 함수로 당일 현황, 주간 실적, 결제 현황을 자동 집계할 수 있습니다.
예: =COUNTIFS(O:O,"검진완료",H:H,TODAY()) → 오늘 검진완료 건수
