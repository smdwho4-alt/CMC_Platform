4. Apps Script API 요청 흐름

예약 등록브라우저 → POST {action:"create", data:{…}} → Apps Script → Sheets 행 추가 → {ok:true, reservationNo:"…"}
목록 조회브라우저 → GET ?action=list[&status=…&dateFrom=…] → Apps Script → Sheets 읽기 → [{…}, …]
상태 변경브라우저 → POST {action:"updateStatus", no:"…", status:"…"} → Apps Script → 해당 행 업데이트
운영 정보브라우저 → POST {action:"updateOps", no:"…", data:{examRoom, doctor, …}} → Apps Script → 19~29컬럼 업데이트
당일 요약브라우저 → GET ?action=summary[&date=YYYY-MM-DD] → Apps Script → {byStatus, byRoom, byPayment, …}
