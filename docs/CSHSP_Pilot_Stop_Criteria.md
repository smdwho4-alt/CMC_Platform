# CSHSP 파일럿 중단 기준 (Sprint I)

> 아래 기준은 파일럿 개시 전 센터장 승인으로 확정하며, 판단 즉시 실행한다. 내부 검토용.

## 1. 즉시 중단 (P1 — 1건이라도 발생 시)

| # | 기준 | 판정 근거 |
|---|------|----------|
| 1 | **AI가 예약을 확정·승인한 것처럼 표현** ("확정되었습니다" 등 단정 표현 1건) | 채팅 캡처 / audit_logs에서 AI 계정(USR-9000)의 RESERVATION_APPROVED 발견 시 최고 등급 |
| 2 | **AI가 진단·처방·검사결과 해석을 노출** (의료 판단 표현 1건) | 채팅 캡처 + SAFETY 미차단 이력 |
| 3 | 본인확인 전/타인에게 개인정보 노출 (이름+전화·생년월일·예약내역 1건) | 채팅 캡처 + 세션 검증 상태 |
| 4 | 로그·감사기록에 개인정보 원문 저장 발견 | Quality Gate D 스캔 FAIL |
| 5 | 데이터 파손 후 복구 실패 (백업 복원 불가) | 복구 절차 수행 기록 |

**즉시 중단 절차** (Failure Manual D 연동):
① 채팅 위젯 차단 (정적 서버에서 chat/ 제거 — admin·엔진·전화 접수는 유지)
② 해당 세션ID·시각·캡처 확보, audit_logs/AI 통계 보존
③ 센터장 + 개인정보보호 책임자 즉시 보고
④ 원인 수정 + 금지응답 테스트(35문항+재현 문항 추가) 전체 PASS 후 재개 승인

## 2. 조건부 중단 검토 (P2 — 반복·누적 시)

| 기준 | 임계값 |
|------|--------|
| 서버 장애로 접수 불가 | 1일 2회 이상 또는 연속 1시간 이상 |
| Safety 오탐(정상 문의 차단)으로 이용 불가 수준 | 일 차단의 30% 이상이 오탐 |
| 예약 데이터 정합 오류(validator) | 일 1건 이상 반복 |
| 알림 큐 적체로 안내 누락 | 2일 연속 |

→ 전산·센터 협의로 **일시 중단(채팅만) 또는 기능 축소(퀵버튼만)** 결정, 24시간 내 보완 후 재개.

## 3. 중단하지 않는 경우 (전화 우회로 계속 운영)

- 채팅 문구·UI 불편, 개별 오탐 차단(의료진 상담 안내로 종결된 경우)
- LLM 경로 장애 → **Key 제거 후 규칙 기반 폴백으로 지속** (중단 아님)
- 일시적 서버 재시작 (5분 이내 복구)

## 4. 기록 의무
모든 중단·재개는 일일점검표 특이사항란과 별도 보고서(일시·기준 번호·조치·재개 승인자)로 남긴다.
