# CSHSP 정식 오픈(Go-Live) 판단 기준 (Sprint I)

> 파일럿 종료 시 센터장 보고용 판정표. 모든 필수 기준 충족 + 보완 목록 합의 시 정식 오픈. 내부 검토용.

## 1. 필수 기준 (하나라도 미충족 시 오픈 보류)

| # | 영역 | 기준 | 측정 방법 |
|---|------|------|----------|
| 1 | AI 안전 | 파일럿 전 기간 **AI 확정 표현·의료판단 노출 0건** | 일일점검표 #10 + Safety 이력 전수 검토 |

## 2. 권장 기준 (미충족 시 조건부 오픈 가능 — 보완 일정 명시)

| 기준 | 목표 |
|------|------|
| AI 채팅 예약 신청 성공률 (정보 완비 시) | 90% 이상 |
| 직원 만족도 | 3.5/5 이상 |
| Safety 오탐률 | 주간 차단의 20% 미만 |
| 채팅 → 예약 전환율 | 파일럿 평균치 기록 (목표선은 오픈 후 설정) |
| SQLite 이관 트리거 점검 | 트리거 4종 미발생 확인 (발생 시 이관 후 오픈) |

## 3. 오픈 범위 결정 (판정 시 함께 결정)

- [ ] 채팅 위젯 공개 범위: 원내 키오스크 → 홈페이지 → 모바일 순 단계 확대
- [ ] LLM 경로 사용 여부: 실키 스모크 + 프롬프트 튜닝 결과로 결정 (미결정 시 규칙 기반으로 오픈 가능)
- [ ] 운영 시간: 24시간 접수 / 승인은 근무시간 — 야간 접수 안내 문구 확정
- [ ] 개인정보 처리방침·이용약관 문구 게시 (법무/개인정보 책임자 승인)

## 4. 판정 절차

1. 파일럿 종료 +3일 내: 전산 담당이 본 표 채점 + 증빙(CSV·점검표) 첨부
2. 검진센터 운영회의 검토 → 센터장 판정: **오픈 / 조건부 오픈(보완 일정) / 파일럿 연장 / 중단**
3. 판정 결과와 보완 목록은 13_회의·보고자료에 보관

## 5. 오픈 후 30일 안정화 기준
- 일일점검표 유지, 주간 품질 게이트, Safety 이력 주간 리뷰 지속
- 중대 이슈(중단 기준 1항목) 발생 시 파일럿 중단 절차 동일 적용
